# 📈 NIFTY Stock Market Prediction using Linear Regression

This project is a machine learning-based approach to predict the NIFTY 50 stock market index using Linear Regression. It includes data preprocessing, visualization, model training, and evaluation using Mean Squared Error (MSE).

##  Project Overview

- Uses historical data of the NIFTY 50 index
- Applies Linear Regression for price prediction
- Evaluates model performance with MSE
- Visualizes actual vs. predicted prices

---

##  Tech Stack

- Language: Python
- Libraries:
  - pandas – for data manipulation
  - numpy – for numerical operations
  - scikit-learn – for implementing Linear Regression and evaluation
  - matplotlib & seaborn – for data visualization


##  Dataset

The dataset consists of historical stock prices of the NIFTY 50 index. It includes fields like:

- Date
- Open
- High
- Low
- Close
- Volume


## Model Evaluation
Algorithm: Linear Regression

Metric: Mean Squared Error (MSE)

Visualization: Line graph comparing actual vs. predicted values
